## Требует владельца

| Что нужно | Зачем | Куда подключить |
|---|---|---|
| Реальный URL VK | Переход и QR | `socialLinks`, элемент `vk` |
| Реальный URL Instagram | Переход и QR | `socialLinks`, элемент `instagram` |
| MAX_BOT_TOKEN | Авторизация реальной доставки заявки | Только backend environment |
| MAX_CHAT_ID либо MAX_USER_ID | Получатель заявок | Только backend environment |
| HTTPS backend hosting и endpoint | Статический Pages не запускает Node-сервер | `NEXT_PUBLIC_LEADS_ENDPOINT`, HTTPS reverse proxy для `/leads` |
| Продажная цена / вариант душевого поддона | Нет подтверждённой цены в источниках | `additionalOptions`, `tray` |

Секреты не публиковать в чате или frontend. Инструкция запуска, ограничения single-instance rate/idempotency и официальный MAX API: `backend/README.md`.

Полноценная реальная доставка заявки в MAX и QR отсутствующих соцсетей не объявляются PASS до предоставления соответствующих данных. Существующие контакты повторно не запрашиваются.
