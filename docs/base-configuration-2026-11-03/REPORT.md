# Базовая комплектация — проверка 2026-11-03

## Принятое правило данных

Уточнение владельца от 2026-11-03: утверждённый в ТЗ перечень используется для стандартных мобильных бань. Его нельзя автоматически применять к домам «Усадьба». В каждой карточке позиции помечаются отдельно: «Включено в базовую комплектацию», «В подарок» или «Уточнить». Неподтверждённые позиции не добавляются в калькулятор как гарантированные.

- Для стандартных мобильных бань отображается владелец-утверждённый базовый список.
- Столы и две лавки обозначены подарком только для БГ-01—БГ-08, согласно источнику каталога.
- Конструкция БГ-18—БГ-28 остаётся на уточнение; БГ-01—БГ-17 и БГ-29—БГ-30 — каркас 100 мм; БГ-31 — брус 90×140 мм.
- У «Усадьбы Практик» и «Усадьбы Простор» планировка и конструкция остаются на уточнение; подтверждённый двухмодульный формат и утепление пола/потолка не смешиваются с перечнем бань.
- У «Усадьбы Веранда» сохранено подтверждение веранды из названия/описания модели, при этом неизвестная планировка остаётся на уточнение.
- Уникальный «Барн Премиум» показывает его опубликованные модельные характеристики. Поясняющий текст, который ошибочно выглядел как включённая позиция, удалён.
- Список неподтверждённых параметров свёрнут по умолчанию и доступен для раскрытия мышью и клавиатурой.
